רוב מה שיש ב־1.4.1 בלתי נראה, וזה מכוון. זה release של הקשחה ואמינות:
יכולת חדשה אחת, ורשימה ארוכה של שינויים שמטרתם שהכשל הבא ייתפס מוקדם,
ידווח ביושר, או לא יקרה בכלל.

## ה־API כבר לא תלוי ב־migrations כדי לעלות

ה־migrations של מסד הנתונים רצו פעם כחלק מעליית השרת, כך שמסד נתונים
שסירב לכתיבות מנע מה־API לעלות בכלל. עכשיו ה־migrations רצים פעם אחת בכל
deploy, כשלב release נפרד. ה־API קיבל גם נקודת קצה של מוכנות, ובדיקת
התקינות שלו בודקת עכשיו את מסד הנתונים, כך שהניטור רואה אות אמיתי במקום
"תקין" שהמשמעות היחידה שלו הייתה שהתהליך רץ.

## כל release עובר את אותו שער

שני ה־workflows שמופעלים על ידי תג, ה־deploy של ה־backend והפרסום
ב־Chrome Web Store, חייבים עכשיו לעבור שער release משותף אחד לפני שמשהו
יוצא. אפשר להריץ את השער כהרצה יבשה לפני התיוג. job מתוזמן גם מדווח כשה־backend
שרץ מפגר יותר מדי אחרי `main`, וה־CI כולל עכשיו סריקה של images
של container ובדיקת תלויות.

## sessions שאפשר לראות

הגדרות החשבון מציגות עכשיו את ה־sessions הפעילים ומאפשרות לבטל כל אחד
מהם. מאחורי זה, ה־refresh tokens עברו מגוף התשובה ל־cookies מסוג HttpOnly,
החלפת ה־session הפכה לטרנזקציה, וה־tokens של אימות ושל איפוס נשמרים
כ־hash ולא כפי שהונפקו.

## widget של GitHub

התוספת היחידה שהמשתמש רואה: מחברים את GitHub עם personal access token,
ו־widget בסרגל הצד מציג התראות, בקשות לסקירה ו־issues שהוקצו לכם.

## תיקונים קטנים

- אירועים ביומן שהגיעו בלי תאריך הוצגו כ"No upcoming events"; עכשיו כל
  אירוע נושא את התאריך שלו.
- ניווט במקלדת עובד שוב ברכיב הבחירה המותאם, ורכיבים לחיצים הם כפתורים
  אמיתיים.
- לכל קריאה יוצאת ל־API חיצוני יש עכשיו timeout.
- `npm` כבר לא נמצא ב־image של ה־container ב־production.
